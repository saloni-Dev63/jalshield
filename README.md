# 🛡️ JalShield — Urban Waterlogging & Septic Risk Assessor

**JalShield** is an interactive environmental vulnerability tool built for the **AWS Bharat Builds Hackathon 2026**. It predicts localized urban flooding risks, septic backflow probability, and shallow groundwater contamination levels across vulnerable sectors in the Delhi-NCR / Faridabad region.

---

## 🚀 Key Features

* **Localized Risk Assessor:** Select specific PIN codes/wards (e.g., Faridabad Sector 37 / Badarpur Border) to evaluate risk.
* **Dynamic Vulnerability Scoring:** Real-time risk calculation based on rainfall intensity (mm/hr), drainage desiltation level, and septic infrastructure age.
* **Shallow Dig Groundwater Hazard Alert:** Predicts soil saturation depth and alerts users to blackwater/toxic seepage risk during shallow excavation (2–6 ft).
* **Actionable Municipal Advisory:** Generates targeted warnings for residents and urban maintenance teams based on severity.
